# Order System REST API

A hypermedia-driven REST API built with Spring Boot, Spring HATEOAS, HAL, and HAL-FORMS.

The API demonstrates how clients can discover resources, navigate relationships, and perform operations through
hypermedia controls rather than hardcoded endpoint URLs.
